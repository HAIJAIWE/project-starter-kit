# 架构图纸模板（填空版）

复制这份，把 `[ ]` 全部填掉。**不需要的部分写"不需要，因为…"，不许留空**——留空的地方就是以后会乱的地方。
任何项目类型都适用。深度可按规模裁剪（小项目产出物更薄），但**裁的是范围不是标准**：第 2、6、8、12 节不能省。

> **先看填好的样板**：`assets/examples/` 里有两份完整实例——个人记账网站、命令行小工具。照着实例填，比照着空模板填可靠得多（尤其"被否的方案"和"现在不做什么"两节）。
