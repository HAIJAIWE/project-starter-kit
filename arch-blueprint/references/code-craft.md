# 编码与可读性（写代码的手艺）

分层决定"代码放哪"，这一份决定"代码写成什么样"。**一条总原则：代码是写给下一个读它的人——大概率是三个月后的你自己。**

---

## 一、命名（性价比最高的功夫）

| 对象 | 用 | 别用 |
|---|---|---|
| 数据/变量 | 名词：`orderTotal`、`pendingMessages` | `data`、`temp`、`x`、`list` |
| 行为/函数 | 动词开头：`parseConfig`、`retryPayment` | `handle`、`process`、`doIt` |
| 布尔 | `isReady`、`hasPermission`、`canRetry` | `flag`、`status2` |
| 集合 | 复数：`users` | `userList`（冗余类型词） |
| 常量 | 说明业务含义：`MAX_RETRY_ATTEMPTS` | `N`、`THREE` |

- 名字长度与作用域匹配：循环里的 `i` 没问题，模块级的 `i` 是灾难。
- 领域通用缩写可以用（`id`、`url`、`api`），自造缩写别用（`usrMgr`）。
- **一个名字说不清它是什么，就该拆函数或改设计**，而不是靠注释补。

## 二、函数与文件

- 一个函数**只做一件事**：能用一句话命名、不带"并且"。
- **早返回**减少嵌套：先处理异常/边界，正常路径留在最外层。
- 参数 ≤3 个；更多就打包成一个结构（也顺便让调用点更可读）。
- 避免"输出参数"和隐藏副作用；有副作用就写在名字里（`saveUser` 而不是 `processUser`）。
- 文件：一个文件一个主要概念；超过约 300–500 行考虑拆（**参考线，不是硬指标**，职责不清就先别拆）。
- 依赖注入 > 在函数内部 new 出外部依赖（否则没法替换、没法测）。

## 三、注释与文档

- 注释写**为什么**和**约束**（"这个接口限 5 次/分钟，所以这里排队"），不写"是什么"。
- 别用注释解释烂代码——先改代码；注释会过期，代码不会。
- TODO 必须带条件或负责人（`TODO(下次迁移时)`），否则永远不做。
- 删掉的代码直接删（版本控制记得住），别留注释坟场。
- 模块顶部一句"这个模块负责什么、不负责什么"，收益极高。

## 四、类型与边界校验（**最容易误解的一点**）

- 类型系统只保证**编译期**；运行时的外部输入一律不可信：用户输入、URL/表单、文件、环境变量、**第三方接口响应**。
- **在边界校验，进核心前收敛**：外部数据 → 校验/转换 → 内部只用干净类型。别在每个函数里重复校验。
- 白名单优于黑名单；校验失败给可理解的错误，不暴露内部结构。
- 别用类型断言/强制转换掩盖问题（"我知道它是这个类型"通常意味着你并不知道）。
- 内部约定用类型表达；跨进程/跨语言用契约文件表达（见 `api-contract.md`）。

## 五、可读性的三个禁止

1. **禁止魔法数字/字符串**：变成常量或枚举（`if (status === 3)` 是灾难）。
2. **禁止深度嵌套**：超过 3 层的 if/循环就该抽函数。
3. **禁止看不懂但能跑的代码**——尤其是 AI 生成的。看不懂就要求讲清楚或重写（见 `ai-code-acceptance.md`）。

## 六、编码规范怎么落地

- 用工具默认配置（formatter + linter），**别在风格上开会**；规则要进 CI，否则等于没有。
- 规则分两类：**可自动修**（格式、导入顺序）→ 交给工具；**需人判断**（命名、拆分）→ 进自审清单。
- 规范不是目的：一堆 lint 通过但没人读得懂的代码，依然是烂代码。

## 七、提交前自审清单（10 条，两分钟）

- [ ] 这段代码属于哪一层、哪个模块？（答不上来先改位置）
- [ ] 有没有硬编码的密钥、路径、开关？（应该进配置）
- [ ] 外部输入校验了吗？失败会怎样？
- [ ] 所有网络/磁盘调用都有超时吗？
- [ ] 错误路径会留下可定位的信息吗？（不是只有一句"出错了"）
- [ ] 命名能让别人不看实现就懂吗？
- [ ] 有没有重复代码？该抽的抽了没有（但别为三行代码造抽象）？
- [ ] 有没有删掉不用的代码、调试打印、临时开关？
- [ ] 改动的接口签名，调用方都同步了吗？
- [ ] 跑过测试了吗？**贴得出输出吗？**

## 八、和"专业"最相关的三条

1. **简单 > 聪明**：让下一个人 5 分钟看懂，胜过炫技。
2. **一致 > 个人偏好**：同一个项目里风格统一，比"哪种更好"重要。
3. **能删的代码是最好的代码**：能不写就不写，能删就删。
