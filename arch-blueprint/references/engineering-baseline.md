# 起项目当天的最小工程基线

分层解决"代码放哪"，这份解决"项目会不会烂"。**不做这些，分层做得再漂亮也会翻车。**
每项给了最小做法、不做的代价、以及什么时候可以暂时跳过。

## 一、必备四项（**任何项目都不许跳过**）

| # | 项目 | 最小做法 | 不做的代价 |
|---|---|---|---|
| 1 | **版本控制** | `git init`；`.gitignore` 排除密钥、依赖目录、构建产物、本地数据库；小步提交 | 改坏了回不去；无法回答"昨天还能跑" |
| 2 | **密钥与配置分离** | 密钥只放环境变量或本地配置文件；仓库里只放 `.env.example`（键名，无真值） | 密钥进仓库 = 必须立刻吊销重发；一旦公开就是事故 |
| 3 | **README** | 三段：怎么装、怎么配（有哪些环境变量）、怎么跑 | 一周后自己也跑不起来 |
| 4 | **可回滚的部署方式** | 至少写清"怎么发布、怎么退回上一版" | 出事时只能干看着 |

## 二、小项目应有的另外六项

| # | 项目 | 最小做法 | 不做的代价 |
|---|---|---|---|
| 5 | **依赖锁定** | 保留 lockfile；依赖只从官方源装 | 今天能跑明天不能跑；供应链投毒 |
| 6 | **日志与错误** | 用户看到人话提示；日志留可定位信息；**日志里不出现密钥和个人信息** | 出事查不到原因；或者把隐私写进日志 |
| 7 | **最小测试** | 业务逻辑 + 接口契约必须有；一条"改了实现就会失败"的测试胜过十条恒真断言 | 每次改动都在赌 |
| 8 | **格式化 / lint** | 用该语言的默认工具，配置一次就不争论风格 | 讨论风格浪费时间；diff 全是空格 |
| 9 | **数据库迁移脚本** | 建表/改字段写成按序编号的脚本，**永不手改生产库** | 环境之间结构不一致，无法重现 |
| 10 | **最小 CI** | 装依赖 → 跑测试 → 构建，失败即红灯 | 靠人记得跑测试 = 迟早不跑 |

## 三、项目变大后补上

| # | 项目 | 触发时机 |
|---|---|---|
| 11 | **备份与恢复演练** | 有真实用户数据时。**只备份不演练 = 没有备份**（要真的恢复一次） |
| 12 | **ADR 决策记录** | 从第一个"我们为什么选它"开始：`docs/adr/0001-xxx.md`（背景 / 选项 / 决定 / 后果） |
| 13 | **环境区分** | 有生产数据时：本地 / 测试 / 生产三套配置互不串（防"测试脚本连了生产库"） |
| 14 | **失败告警** | 无人值守运行时：出错要主动通知，不能只写日志 |
| 15 | **依赖与漏洞检查** | 上线后定期跑依赖审计；关注安全公告 |
| 16 | **权限与审计** | 多人协作或含公司数据时：谁能改什么、改了什么要留痕 |

## 四、按规模的"最少要做"

| 规模 | 至少做 |
|---|---|
| 玩具 / 脚本 | 1、2、3 |
| 小项目（自己用或小范围分享） | 1–8 |
| 有真实用户 | 1–13 |
| 多人协作 / 含敏感数据 | 1–16 |

## 四·补、配套：写代码本身的规矩（工程基线只管"项目"，这些管"代码"）

| 主题 | 文件 |
|---|---|
| 命名、函数、注释、类型与边界校验、自审清单 | `code-craft.md` |
| 接口契约、输入校验、HTTP 设计、版本兼容 | `api-contract.md` |
| 测什么不测什么、假对象、覆盖率、落地顺序 | `testing-strategy.md` |
| 错误分类、超时、重试、幂等、降级、并发事务 | `failure-design.md` |
| 认证授权、注入、密钥、隐私、AI 项目额外项 | `security-checklist.md` |
| 性能排查、缓存、性能预算、调试流程、可观测 | `perf-and-debug.md` |
| Git 纪律、版本管理、渐进发布、数据迁移、重构 | `release-and-evolution.md` |
| 环境可复现、一键启动、种子数据、跨平台陷阱 | `dev-environment.md` |
| 多语言、无障碍（有对外需求时） | `i18n-and-a11y.md` |

**最小组合**：`code-craft.md` + `failure-design.md` + `testing-strategy.md` 三份，能挡住小项目八成的"能跑但不能维护"。

## 五、三条容易反着做的规矩

1. **先能回滚，再谈优化**。没有回滚能力的重构是赌博。
2. **密钥泄露的第一动作是吊销，不是删 commit**。删了也在历史里。
3. **备份要演练**。没演练过的备份，等于赌运气。
