# 安全与隐私清单（编码层面）

**心态三句话**：输入是恶意的；前端代码人人可见；URL 用户会随便改。
权威依据：[OWASP Top 10](https://owasp.org/projects/top-ten)、OWASP ASVS、OWASP Cheat Sheet Series（**版本以官方最新为准**，Top 10 近年有多次更新）；AI/智能体项目另加 OWASP Securing Agentic Applications 的思路。

---

## 一、认证与授权（最常见的真实漏洞在这）

| 项 | 做法 |
|---|---|
| 认证 | 会话/令牌的生成与校验交给成熟库；密码用慢哈希（bcrypt/argon2 一类），**绝不自己写加密** |
| 授权 | 每次访问对象都校验**归属**：`/orders/123` 不能只看"登录了没"，要看"这单是不是他的"（越权 IDOR 是头号问题） |
| 默认拒绝 | 新接口默认没权限，显式开；别默认放开 |
| 敏感操作 | 改密码/删数据/提额度要二次确认或重新验证 |
| 会话 | 有有效期、能主动失效；退出要真失效（不只是前端清缓存） |

## 二、注入类（都是"把数据当代码执行"）

| 类型 | 错误做法 | 正确做法 |
|---|---|---|
| SQL | 拼字符串查询 | **参数化查询/预编译**；ORM 也注意原始 SQL 拼接 |
| 命令 | 拼 shell 命令 | 避免调 shell；必须调时用参数数组，禁拼接 |
| 模板/表达式 | 用户输入进模板或 eval | 不 eval 用户输入；模板变量转义 |
| 路径穿越 | 直接用用户给的文件名/路径 | 限定在根目录内、规范化后校验、用随机文件名 |
| 反序列化 | 反序列化不可信数据 | 用安全格式（JSON）+ 显式 schema 校验 |

## 三、前端与浏览器相关

- **XSS**：输出转义是默认动作；别用 `innerHTML`/`dangerouslySetInnerHTML` 塞用户内容；富文本要净化。
- **CSRF**：Cookie 加 `SameSite`；关键操作加令牌或要求非简单请求。
- **CORS**：别 `Access-Control-Allow-Origin: *` 还带凭据；白名单来源。
- **敏感信息**：前端包与页面源码人人可见，**密钥、内部地址、算法细节都不能放前端**。

## 四、文件上传与外部内容

- 校验类型（按内容而非扩展名）、大小上限；
- 存到**不可执行**的位置，随机文件名，别用用户提供的文件名；
- 图片/文档处理库要更新（解析器是最常被攻击的组件）；
- 抓取来的外部内容当作不可信数据处理（别直接渲染/执行）。

## 五、密钥与凭据

- 只放环境变量或密钥管理服务；仓库里只留 `.env.example`。
- 不进代码、不进日志、不进前端、不进截图、不进报错信息。
- **泄漏第一动作是吊销/轮换**，不是删 commit（历史里还在，且可能已被复制）。
- 每个密钥最小权限：能只读就别给写，能限定 IP/范围就限定。
- 定期轮换；离职/换机器时轮换。

## 六、依赖与新库

- 只从官方源安装；保留锁文件；名字相近的包（typosquatting）要警惕。
- 定期跑依赖审计；关注安全公告；长期不维护的库别用。
- 引入新库前问：标准库能不能做？谁维护？许可证允许商用吗？

## 七、日志、隐私与合规

- 日志里**不出现**：密码、令牌、密钥、完整身份证/银行卡、手机号明文（要记就脱敏/哈希）。
- 收集个人信息遵循最小化：能不问就不问，能不留就不留，明确留存期限与删除方式。
- 用户数据发给第三方（含大模型）前要想清楚：**这算不算把用户数据交给别人**，是否有授权与合规依据。
- 备份与导出同样适用隐私要求（备份里的明文数据也是风险）。

## 八、滥用与成本防护

- 登录、注册、短信、验证码、AI 调用都要限流（AI 尤其：一次滥用能烧掉预算）。
- 关键操作要有审计记录（谁、什么时候、做了什么）。
- 内部管理接口不要暴露在公网。

## 九、AI / 智能体项目的额外项

| 风险 | 防线 |
|---|---|
| 提示注入（用户输入操纵模型行为） | 系统提示与用户输入分离；不把用户输入当指令执行 |
| 工具调用越权 | 工具按最小权限授权；危险操作（删文件/转账/发消息）要人工确认或沙箱 |
| 模型输出直接执行 | **永不直接执行模型生成的代码/命令**，要过校验与白名单 |
| 数据外泄 | 敏感数据脱敏后再发；明确哪些数据不许出本机 |
| 成本失控 | 每用户/每日配额 + 预算上限 + 降级策略 |

## 十、交付前安全自查（12 条）

- [ ] 每个对象访问都校验归属？
- [ ] 所有查询参数化？没有拼接 SQL/命令？
- [ ] 用户内容输出都转义？没用 innerHTML 直塞？
- [ ] Cookie 有 SameSite？关键操作防 CSRF？
- [ ] CORS 是白名单，不是 `*`？
- [ ] 上传做了类型/大小校验并存在不可执行目录？
- [ ] 密钥不在代码/日志/前端？泄露了知道怎么吊销？
- [ ] 日志没有密码/令牌/完整个人信息？
- [ ] 依赖审计过、锁文件在？
- [ ] 登录/短信/AI 调用有限流？
- [ ] 错误信息不暴露内部堆栈与路径？
- [ ] 数据库/云账号是最小权限？
